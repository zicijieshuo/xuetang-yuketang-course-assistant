# 架构说明

## 模块边界

- `models.py`：课程、任务、平台完成度解析和纯播放监测状态机。
- `storage.py`：本机 UTF-8 JSON 原子保存和滚动日志。
- `browser.py`：独立登录目录、浏览器准备、真实可见性和弹窗检测。
- `site.py`：集中站点适配器和可校准 CSS 控件；只读取 DOM 并点击正常控件。
- `worker.py`：独立 Playwright 线程、命令队列、每 3 秒监测、用户暂停和窗口等待、通知及任务持久化。
- `gui.py`：中文桌面界面、课程勾选、队列、日志、托盘通知、链接补充、控件设置和隐私诊断。
- 详细教程从 `docs/使用教程.md` 以 UTF-8 读取并由 QTextBrowser 渲染；右上角使用说明打开非模态单实例窗口，不投递播放命令。当前长标题单行省略并提供完整提示，底部为唯一开发者水印。
- `assistant.spec` / `build.ps1`：Windows 目录式发行包，包含 Python、Qt 和 Playwright 驱动；首次运行另外准备浏览器。

## 线程与关闭

GUI 不直接访问浏览器，所有命令投递给唯一工作线程。暂停、停止、退出通过事件打断扫描和等待；网页加载单次超时 15 秒，随后在操作边界响应。退出等待工作线程关闭浏览器，避免强制终止线程损坏独立登录目录。全局单实例锁避免配置目录冲突。

关闭独立浏览器时优先发送正常的 `Browser.close`，等待进程退出以保存登录配置；超时后才终止该专用进程。不会关闭日常浏览器。

急停命令优先于普通命令处理。窗口恢复保留已经执行过一次刷新确认的状态，避免隐藏后重复刷新或自动重播。手动添加的课程入口持久保存，刷新列表时保留。

急停同时丢弃其之前排队但尚未执行的命令，避免停止后又执行旧的“开始”。章节目录按照公开 `ChapterNavItem` 的 `.nav-item-title.is-expand` 状态展开，与知识目录的 `.expand-icon.is-expanded` 分开识别。二倍速设置无效时尝试其余菜单选项，从最高倍速向下降级。

## 发行包自检

`main.py --self-test` 或发行 exe 的 `--self-test` 在离屏模式绘制本程序示例界面，检查 UTF-8 文档和打包后的 Playwright Node 驱动，并输出本机数据目录的 `self-test` 子目录中的 `smoke-report.json` / `ui-preview.png`。测试记录与真实任务隔离，不打开真实站点。设置 `XUETANG_SMOKE_BROWSER` 为已安装测试 Chromium 的路径时，还会启动无头临时浏览器验证 Playwright 控制链路，不使用登录配置。

也可设置 `XUETANG_SMOKE_CHANNEL=msedge` 验证已安装 Edge 的控制链路。

## 已实现的约束

- 只允许 `https://dcc.yuketang.cn` 的任务链接。
- 完成判定只接受当前视频状态的“已完成”、Completed 或明确 100%；不将播放结束视为完成。
- 完成后直接导航下一个任务，不依赖暂停控件。最后一个任务完成后通过 about:blank 卸载播放器，避免 100% 早于媒体结束时继续播放。
- 播放结束等待 60 秒后仅刷新一次，刷新后预留 15 秒给页面完成度更新，仍未确认则暂停。
- 隐藏状态不计入卡顿时间；正常可见状态卡顿 60 秒提示人工处理。
- 通过本机回环端口连接正常启动的独立浏览器，使用 `connect_over_cdp(no_defaults=True)`。默认关闭焦点模拟，用户开启后台播放后，在当前页面 CDP 会话设置 `Emulation.setFocusEmulationEnabled` 并读取页面状态确认生效。新标签页接管时重新应用。端口随机分配，仅监听 127.0.0.1。
- 检测到本机 Edge 时默认使用它的独立登录窗口；否则首次使用下载专用 Chromium（不下载额外无头 shell）。Chromium 启动失败时尝试已安装 Edge，以处理 Windows 运行库和媒体编解码兼容问题。
- 日志只记录程序生成的信息和错误类型，不保存原始浏览器异常、Cookie、令牌、HTML 或安装输出。

## Windows 打包依赖

Qt 6.11 使用 Windows 系统 ICU。构建时清理其他应用 Poppler 的 PATH 目录并排除其同名 `icuuc.dll`，防止发行包中的错误 ICU 覆盖系统依赖而导致 QtCore 导入失败。发行包自检必须实际运行 exe，不以源码运行成功代替。
# 学习内容总览导航

总览使用真实 DOM 的视频图标及独立状态筛选。视频点击通过普通 popup 事件回调接管新页，同时更新 BrowserSession 的对话框监听和 CDP 窗口状态会话；关闭本次旧页，保留一个工作标签页。不调用 bring_to_front；仅用户开启后台播放时使用浏览器焦点模拟。

后台偏好持久化于 preferences.json。所有模式切换在工作线程处理；失败恢复旧选项并暂停提示。SiteAdapter 后台模式忽略物理最小化状态，仍读取浏览器报告的页面可见性。模式切换不改变用户暂停或停止状态。

最小化窗口可能无法完成菜单的鼠标命中。后台模式下向已确认的原播放器控件触发鼠标及点击事件，并再次读取实际静音和倍速确认；前台模式沿用真实鼠标操作。不直接赋值媒体属性。

后台目录扫描与视频入口导航同样使用已识别 DOM 控件的点击事件，避免最小化后的鼠标操作超时；保留路由校验及新标签页接管。

后台视频入口点击期间，在本站 frame 中临时包装 window.open，仅截取 dcc.yuketang.cn 的已验证数字视频路由。正常目录控件仍负责产生路由，适配器随后恢复 window.open 并在原页面通过正常导航打开该链接，不创建新标签页，不进行恢复窗口或激活操作。其他 URL 沿用原窗口行为；无法唯一解析的视频路由暂停提示。

实际 XtPlayer 的倍速点击要求选项进入后的鼠标位移。适配器在同一菜单项内执行两次真实 hover 后点击，随后读取 video.playbackRate 确认；不赋值媒体属性。

XtPlayer 音量更新有 100ms 节流，图标更新可能早于实际 volume 赋值。准备播放时等待 loadedmetadata 与初始化，遇到已静音图标但实际媒体未静音时，通过控件复位并隔开 180ms 再静音，最多两轮；每轮读取当前媒体状态。播放启动后再次确认静音与倍速，修复加载过程的状态重置。
