# 学堂云本地视频播放助手

## 适用学校与联系渠道

项目展示名称为“学堂云/雨课堂刷网课助手”，专为“滇池学院”开发与适配，目前仅验证 dcc.yuketang.cn。其他学校的域名、版本或播放器配置可能不同，不保证能够使用。如果无法使用，请联系 QQ：1658399029，并说明学校、平台网址、软件版本及具体问题。

## 使用流程

1. 双击发行目录中的 `学堂云播放助手.exe`。保留同目录 `_internal` 文件夹。
2. 点击“打开浏览器”。检测到本机 Edge 时默认选用 Edge；否则首次使用准备专用 Chromium。两者使用独立登录目录，Chromium 启动失败时会尝试已安装的 Edge。
3. 在专用浏览器中自行完成登录和验证码，进入 `https://dcc.yuketang.cn/pro/courselist` 的“我听的课”。程序不读取密码。
4. 点击“刷新课程”，勾选要处理的课程，然后点击“开始”。程序扫描所选课程，跳过作业、考试、未知类型、锁定视频和已完成视频。
5. 默认需保留播放标签页可见；勾选“绕过后台暂停检测”后允许最小化或切换标签页。鼠标和键盘焦点可以留在其他应用。
6. 点击程序“暂停”后必须点击“继续”。“停止”保留队列记录；再次开始会重新读取平台目录和进度。

## 播放与完成判定

- 每次播放先通过播放器控件静音并确认，然后选择 2×；没有 2×时采用已识别菜单中的最高倍速。
- 没有识别到倍速菜单时保留播放器当前倍速并提示。如页面实际存在倍速菜单，可在“控件设置”中校准。
- 静音设置失败、完成度不明确或播放器不唯一时暂停任务，不强制点击。
- 只有当前视频专属控件显示“已完成”或 100% 才切换；确认后直接导航下一条，不等待暂停控件。最后一条完成后卸载播放器。平台可能在低于 100% 时直接显示“已完成”，程序尊重平台显示。
- 播放结束后等待 60 秒，仍未完成则刷新一次；刷新后再等待 15 秒，仍未完成则通知并暂停，不自动重播。
- 未开启绕过后台暂停检测时，最小化或切换播放标签页会通知一次，等待你恢复；开启绕过后台暂停检测后继续处理队列。不会主动抢占窗口。
- 浏览器使用静音启动参数，避免页面自动播放瞬间发声；同时仍确认播放器自身的音量为 0 或静音。

## 页面适配

选择器来自学堂云公开 Vue 前端资源及真实登录页面检查，课程目录、静音及二倍速已联调，完整验证范围见验证记录。页面识别失败时可查看“诊断”给出的控件数量，或通过“控件设置”调整 CSS 选择器。设置保存到本机，重启后仍有效。

本机 Chromium 曾出现 Windows 并行配置错误，已安装 Edge 的控制链路验证通过。遇到浏览器无法启动时优先选择 Edge；切换浏览器后需要在其独立窗口重新登录。

如果曾出现“DLL load failed while importing QtCore”：使用整个新版发行目录（含 `_internal`），不要只复制 exe。新版已排除误带入的 Poppler ICU，并通过实际 exe 启动自检。

提供“添加链接”补充未出现在列表中的课程或视频入口，只接受该学堂云域名的 HTTPS 链接。视频链接仍扫描它所在页面的课程目录，不视为单个视频任务。

登录失效、验证码、网页弹窗或关键控件不明确时：在浏览器中自行处理，然后点击“继续”。若网页结构变化，先校准控件；目录排序变化则停止并重新开始。

## 数据位置

本机 `%LOCALAPPDATA%\XuetangAssistant` 保存独立浏览器登录目录、浏览器运行时、控件设置、任务记录及滚动日志。日志不写入密码、Cookie、令牌或原始 HTML。登录目录本身含浏览器会话，请勿分享。

退出程序会停止任务并关闭专用浏览器。再次启动不会自动播放，必须重新勾选并开始，以平台当前进度为准。
# 课程刷新修复（2026-10-08）

平台常驻的验证码 iframe 可能完全透明并位于屏幕外，程序仅在验证码实际出现在视口且非透明时暂停。正常刷新导致旧页面或 iframe 销毁时，会短暂等待并重新读取；真正显示的验证码仍须手动处理。新版请关闭旧助手后启动，再点击打开浏览器、刷新课程。
# 学习内容总览入口（2026-10-08）

课程首页先进入学习内容总览时，助手会按总览的目录顺序识别视频图标、完成状态及锁定状态，跳过作业和考试。点击视频打开新标签页时，会接管该视频标签页并关闭本次导航的旧总览页，保持一个工作标签页。无需手动先进入视频页面。升级后请关闭旧助手并启动新版本，重新开始以扫描最新目录。

# 绕过后台暂停检测

主界面新增“绕过后台暂停检测”复选框，首次默认关闭。勾选后允许最小化浏览器或切换标签页，助手通过浏览器焦点模拟继续操作当前视频；选项自动保存在本机，下次启动沿用。取消勾选恢复原来的窗口可见性检查和恢复窗口通知。

可以在浏览器打开前或任务运行中切换。用户点击“暂停”后，开启后台选项不会恢复任务，仍需点击“继续”；“停止”仍保留队列。换到新的视频标签页时会自动应用已选模式。

后台模式不修改学习进度、不调用上报接口；完成仍以平台显示的已完成或 100% 为准。浏览器关闭、网络异常和平台弹窗仍需处理。当前确认情况见验证记录。
# 完成后直接切换视频

平台显示当前视频已完成或 100% 后，助手记录完成并直接打开下一个视频，不再点击或等待暂停按钮。因此暂停控件异常不会阻断完成后的切换。最后一条完成后打开本地空白页，卸载播放器并停止媒体，保留队列和完成记录。手动暂停、停止仍使用原有逻辑。
# 切换视频后的静音与倍速

助手会等待媒体元数据加载及播放器初始化，再检查实际视频音量。静音图标与媒体音量不同步时，会复位开关并隔开播放器的音量节流间隔，重新确认静音；不会只凭图标认定静音。播放开始后再次确认静音和倍速，播放器重置倍速时重新选择二倍速。持续无法静音时仍暂停并提示。
# 后台切换保持最小化

绕过后台暂停检测模式下，视频目录入口产生的视频链接在原工作标签页打开，不再创建新的播放标签页，因此切换下一条时不会因为平台的新标签页行为恢复最小化窗口。前台模式仍沿用平台的新标签页入口及接管流程。
