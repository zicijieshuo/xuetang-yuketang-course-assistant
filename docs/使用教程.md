# 学堂云助手 · 使用教程

在本机播放所选课程的未完成视频。 **作业、考试、已完成视频和未开放内容会自动跳过。**

## 1. 首次启动与浏览器准备

1. 解压完整发行包，双击  **学堂云播放助手.exe** 。必须保留同目录的  **_internal**  文件夹，不能只复制 exe。
2. 默认选择本机已安装的  **Edge** ，点击  **打开浏览器** 。未安装 Edge 时可使用专用 Chromium；首次准备浏览器需联网并等待安装进度完成。
3. 程序使用独立浏览器登录目录，与日常浏览器分开。更换浏览器类型可能需要重新登录。

## 2. 手动登录与选择课程

1. 在助手打开的专用浏览器中手动登录学堂云，完成验证码，进入  **我听的课** 。
2. 返回助手，点击  **刷新课程** ，勾选需要播放的课程； **全选** 可一次勾选列表中的所有课程。
3. 列表没有显示课程时，可通过  **添加链接** 补充该站点的课程入口，并填写显示名称。
4. 点击  **开始** 。助手会重新扫描平台目录和进度，按所选课程及目录顺序建立视频队列。

>  **登录提示：** 登录失效或出现验证码时，先在专用浏览器中处理，再点击助手的「继续」。不要关闭专用浏览器。

## 3. 播放、静音与倍速

- 每条视频开始前，通过播放器控件设置并确认  **静音** ，优先选择  **2×** 。
- 没有 2× 时选择可用最高倍速并记录日志；无法识别倍速菜单时保留当前倍速并提示。
- 当前课程、视频、实际选择的倍速、平台完成度与队列位置显示在  **当前播放** 区域。
- 队列中蓝色行表示播放中的视频，下面的  **运行日志** 记录扫描、切换和异常。
-  **只有平台显示已完成或 100% 才切换下一条。** 全部队列完成后卸载播放器，停止播放并发送通知。

>  **不要只根据视频播放到末尾判断完成。** 播放结束后，助手最多等待 60 秒并刷新状态一次；刷新后再等待 15 秒，仍未确认完成则暂停并提示。

## 4. 绕过后台暂停检测

 **开启后可以最小化后继续播放，绕过学堂云的必须在前台才能播放的检测**

- 勾选  **绕过后台暂停检测**  后，可最小化播放浏览器或切换标签页，助手继续处理视频队列。切换下一视频使用原工作标签页，保持最小化状态。
-  **关闭时需保持播放窗口和播放标签页可见。** 最小化或切换标签页后，助手等待窗口恢复，恢复可见后自动继续。
- 开关可以在打开浏览器前或任务运行中调整，并保存在本机，下次启动沿用。
-  **开启开关不会解除手动暂停，也不会重新启动已停止任务。** 完成仍以平台状态为准。

## 5. 暂停、继续、停止与退出

| 操作 | 作用 |
| --- | --- |
| 暂停 | 暂停当前任务；必须手动点击继续才恢复。 |
| 继续 | 在手动暂停或处理异常后恢复任务。 |
| 停止 | 停止任务并保留队列记录；再次开始会重新扫描平台。 |
| 使用说明 | 打开本教程；不会暂停任务，可边看教程边运行。 |
| 退出助手 | 停止任务并关闭专用浏览器；下次启动不会自动播放。 |

## 6. 常见异常与处理

-  **需要处理 / 登录过期 / 验证码：** 在浏览器完成相关操作，然后点击继续。
-  **页面加载失败：** 助手最多重试两次。检查网络或页面加载情况，处理后点击继续。
-  **静音确认失败：** 查看当前播放器是否加载完成、音量控件是否正常；助手会尝试同步静音状态，持续失败时暂停提示。
-  **视频结束但平台未确认：** 等待助手的状态检查；若最终暂停，检查平台完成度后再继续，不要以本地队列代替平台进度。
-  **无法识别目录或控件：** 通过诊断查看控件数量；只有页面发生变化时才使用控件设置。目录排序变化时停止并重新开始。
-  **浏览器被关闭：** 重新打开专用浏览器，检查登录状态并重新开始。

## 7. 本机数据与升级

点击  **数据目录** 可打开本机记录位置。登录配置、队列、日志及开关偏好保存在 `%LOCALAPPDATA%\XuetangAssistant`。

升级时先关闭旧助手，再解压完整新版并运行。 **现有登录配置和偏好会继续使用。** 源码及教程使用 UTF-8 编码，教程随程序打包，可离线阅读。
